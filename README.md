📌 Project Overview
This project presents an end-to-end data analysis of bakery sales performance. The goal is to clean unstructured raw transaction data, uncover daily and monthly purchasing patterns, identify top-selling products, and provide actionable business insights to boost operational efficiency and revenue.

🛠️ Tools & Technologies Used
Python (Pandas): Data cleaning, handling missing values, standardizing column formats, and processing raw transactional data.

Power BI: Data modeling, dynamic DAX measures, interactive visual dashboards, and performance tracking.

🧹 Data Cleaning Pipeline (Python)
Handled missing and null values across transaction records.

Formatted date and time columns for seamless time-series analysis.

Filtered out duplicate entries and categorized products into distinct menu items.

Exported the cleaned dataset into a structured format ready for Power BI modeling.

📊 Key Insights & Business Findings
Peak Sales Hours: Identified the busiest hours of the day (morning rush vs. afternoon tea) to optimize staffing and fresh production schedules.

Top Performing Items: Highlighted top revenue drivers and best-selling pastry/coffee combinations.

Sales Trends: Analyzed day-of-week and month-over-month sales velocity to forecast inventory demand.
